# longhuynh55.github.io

Personal site of **Liêu Hoài Phúc** — Data Analyst & researcher. Live at <https://longhuynh55.github.io>.

Built with [al-folio](https://github.com/alshedivat/al-folio) (Jekyll) and deployed to GitHub Pages by `.github/workflows/deploy.yml` (push to `main` → build → `gh-pages` branch).

## Where to edit

| What | File |
| --- | --- |
| Name, URL, site settings | `_config.yml` |
| Home / bio | `_pages/about.md` |
| Publications | `_bibliography/papers.bib` |
| Projects (`category: research` / `data science` / `full-stack`) | `_projects/*.md` |
| News on the home page | `_news/*.md` |
| CV page / PDF | `_data/cv.yml`, `assets/pdf/resume.pdf` |
| Social links | `_data/socials.yml` |

The previous Astro version of this site is kept on the `astro-backup` branch.

See `docs/` for al-folio's own documentation.
